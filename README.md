# useful_linux

This repository documents practical Linux workflows for Ubuntu on an ASUS TUF F16 laptop.

It was created to centralize scripts, setup notes, and operational guides that help automate recurring tasks and improve day-to-day system usage. The main focus is reducing manual setup effort and keeping a reliable reference for common maintenance, productivity, and development routines.

In this repository, you will find:

- installation and bootstrap automation scripts;
- documentation for hardware-specific optimizations;
- sync and backup workflows for common tools;
- practical notes for daily Ubuntu usage.

## Repository Scope

The content is focused on:

- Ubuntu-based environments;
- ASUS TUF F16 usage and optimization;
- repeatable setup and configuration steps;
- simple, practical Linux automation.
